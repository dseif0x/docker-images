Things I've built

Open-source work: Kubernetes operators from my homelab, build tooling and systems code.

Go

agents-operator

Self-hosted mission control for AI coding agents on Kubernetes. Every session is its own pod with persistent storage, and the agent's terminal is streamed to the browser.

KubernetesWebSocketsHelm
Go

games-operator

Game streaming on Kubernetes: one Go binary acts as a Moonlight-compatible host and launches each game in its own GPU-backed pod, playable from any Moonlight client or the browser.

KubernetesGPUStreaming
Go

k8s-gpu-autoprovision

A controller that powers GPU nodes on when GPU workloads are pending and back off when they're idle, via simple scale-up and scale-down webhooks.

os-docker

Builds bootable UEFI disk images for Linux VMs using nothing but Docker: every distro is a plain Dockerfile, and a small Go tool packs the root filesystem into a GPT image with GRUB. amd64 and arm64.
